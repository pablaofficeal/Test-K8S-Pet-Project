# Test-K8s-Pet-Project

[English](README.md) | **Русский**

> ⚠️ **Перед запуском проекта перегенерируй JWT-ключи.**
> Ключи в `.env` — публичные моки, их небезопасно использовать где-либо кроме локальной разработки.
> См. [docs/jwt-keys.ru.md](docs/jwt-keys.ru.md).

## Сервисы

| Директория  | Описание                                          |
|-------------|---------------------------------------------------|
| `auth/`     | Сервис авторизации (Python), выдаёт JWT-токены    |
| `backend/`  | Бэкенд-сервис (Go)                                |
| `gateway/`  | API-шлюз (Rust): маршрутизация, middleware, метрики |
| `frontend/` | Веб-клиент (React + Vite + TypeScript)            |
| `verify/`   | Подтверждение почты (Go, RabbitMQ)                |
| `migrations/` | Миграции схемы БД (Go)                          |
| `Infra/`    | Конфиги инфраструктуры (PostgreSQL)               |
| `k8s/`      | Манифесты Kubernetes                              |

## Конфигурация

`.env` лежит в репозитории намеренно и содержит **только моковые значения** для локальной разработки. Реальные секреты в него класть нельзя; храни их в некоммитимом файле, например `.env.prod`.
